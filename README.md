# Indonesian Railfurs

Website resmi komunitas **Indonesian Railfurs** — wadah penggemar perkeretaapian
dan komunitas furry di Indonesia.

## Daftar Situs

| Situs | Deskripsi | URL |
|---|---|---|
| Situs utama | Profil komunitas, arsip event, peta jalur | https://railfurs.my.id |
| Pendaftaran | Formulir & alur pendaftaran anggota | https://join.railfurs.my.id |
| Wiki | Artikel seputar furry & perkeretaapian | https://wiki.railfurs.my.id |
| Tiket | Pemesanan tiket acara & pembayaran QRIS | https://tiket.railfurs.my.id |
