# Indonesian Railfurs - Member Dashboard & Applicant Portal

Paket mandiri portal dasbor anggota resmi dan portal pendaftar Indonesian Railfurs.

## Fitur Utama Termasuk:
1. **Halaman Autentikasi / Login**: Mendukung akun anggota terverifikasi dan akun calon anggota.
2. **Mode Pendaftar Eksperimental**: Lembar manifest sinyal jalur kereta (status Pending, Ditolak dengan revisi, Diterima).
3. **Kartu Tanda Anggota (KTA Pass)**: Desain eksklusif IC Transit Pass dengan foto karakter, stempel, dan data keanggotaan.
4. **Katalog Agenda & Beli Tiket Joyride**: Pemilihan kursi kereta eksekutif dan penerbitan Boarding Pass otomatis.
5. **Manajemen Akun & Modal Edit Berkas**: Ubah biodata dan foto profil fursona/OC secara langsung.

## Cara Menjalankan
```bash
npm install
npm run dev
```
